# Support

This is a community open source project, not an AWS service or product.

## Getting help

- **Bugs and feature requests:** open a [GitHub issue](https://github.com/awslabs/agent-behavior-validator/issues)
- **Questions and usage help:** open a GitHub issue with the question label
- **Security vulnerabilities:** see [SECURITY.md](SECURITY.md) — do not open a public issue

## What to expect

Support is community-based and best-effort. This project is **not covered by
AWS Support plans**, and there is no service level agreement. Responses come
from maintainers working on it alongside other responsibilities.

## Stability

Both packages are pre-1.0 and published with the
`Development Status :: 4 - Beta` classifier. APIs may change between minor
versions — pin a version if you depend on it.
